# Диагностика навыков

Статическая страница для GitHub Pages. 100 заданий: 30 по Java, 30 по SQL, 18 по информационной системе детского сада, 18 по офлайн-приложению и 4 по общей практике. Из них 89 проверяются автоматически, 11 требуют ручного разбора. Ответы сохраняются в Firebase Realtime Database по персональному коду из фрагмента URL; локальная копия позволяет продолжать при временном отсутствии связи.

К каждому заданию можно добавить комментарий или оставить комментарий вместо ответа. Выбранный вариант получает автоматическую отметку «верно» или «неверно»; комментарий без ответа идет на ручной разбор. Комментарий можно дополнить после отправки. Черновики вариантов и открытых ответов тоже синхронизируются.

## Запуск для проверки

Откройте локальный сервер в этой папке, например `python -m http.server 8765`, затем перейдите на `http://localhost:8765/?preview=1`. Режим просмотра сохраняет данные только в браузере и явно показывает этот статус.

## Настройка облака

1. Создайте отдельный проект Firebase и Realtime Database на бесплатном плане.
2. Установите правила из `database.rules.json`.
3. Запишите URL базы в `config.js` (без завершающего `/`). URL базы не является секретом.
4. Создайте случайный код из 48 шестнадцатеричных символов и добавьте через консоль администратора запись `attempts/<код>` со значением `{ "version": 1 }`. Код нельзя помещать в репозиторий.
5. Включите GitHub Pages и передайте ученице ссылку вида `https://<пользователь>.github.io/<репозиторий>/#attempt=<код>`.

Корень базы и список попыток закрыты правилами. Код в ссылке дает доступ к одной попытке, поэтому ссылку нужно передавать только ученице и наставнику. Это диагностический тест, а не защищенный экзамен: правильные варианты находятся в общедоступном JavaScript.

## Проверка

- Откройте персональную ссылку на компьютере, ответьте на один вопрос и дождитесь статуса `Сохранено в облаке`.
- Откройте ту же ссылку на телефоне и проверьте ответ и результат.
- Создайте черновик практического ответа на телефоне, затем проверьте его на компьютере.
- При временном отсутствии связи страница сохраняет ответ локально и синхронизирует его после восстановления сети.
- Оставьте комментарий без ответа и убедитесь, что задание отмечено завершенным без автоматического балла.
- Добавьте комментарий к выбранному варианту и проверьте его в выгрузке для наставника.
